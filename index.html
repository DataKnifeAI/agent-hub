Proposed · plugin layout

            
One folder, two manifests

            

              Cursor and Claude Code plugins share the same structure. Each plugin lives under
              plugins/<name>/ in agent-hub and pulls skills from agent-skills, so
              there's still one source of truth. A marketplace file at the repo root lets Claude
              Code install straight from GitHub.
            

          

          
agent-hub/
├── .claude-plugin/marketplace.json   # lists plugins/*
└── plugins/
    └── dataknifeai/
        ├── .cursor-plugin/plugin.json
        ├── .claude-plugin/plugin.json
        ├── skills/  → agent-skills/skills
        ├── rules/   # conventional commits, small MRs
        ├── commands/
        └── .mcp.json    # templates, secrets via env

Other ways to install

          
The one-liner above wraps scripts/install-skills.sh. These work too.

        

        

          

            
Makefile

            
From a checkout of agent-skills. Symlinks into ./.cursor/skills by default.

            
make install
make install-user
make install ONLY=gh-cli,kubectl-cli

          

          

            
Installer script

            
Point --target at any tool's skills folder. Add --copy for committed installs.

            
./scripts/install-skills.sh --target .claude/skills
./scripts/install-skills.sh --target .github/skills --copy
./scripts/install-skills.sh --dry-run
